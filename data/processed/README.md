# Processed public data

This folder contains aggregate, non-sensitive inputs used for public Round 3 checks.

- `ba_load_weights_public_u0663.csv`: aggregate BA load weights from the continuity-sensitivity scenario (`u=0.663`). These are used only as BA weights; scenario totals are scaled to other `u` values.
- `ba_effective_emission_factor_egrid2023_rev2.csv`: BA-level total-output and combustion-output carbon-intensity factors derived from EPA eGRID2023 Revision 2.
- `ba_fuel_share_egrid2023_rev2.csv`: BA-level fuel-type shares.
- `ba_fuel_groups_egrid2023_rev2.csv`: BA-level fossil/nuclear/renewable group shares.

No facility identifiers, addresses, coordinates, or facility-level records are included.
