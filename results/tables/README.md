# Results tables

Aggregate outputs used in the Round 3 manuscript and response letter.

Important files:

- `scenario_totals_round3_total_output.csv`: headline scenario electricity and CO2 totals.
- `denominator_audit_round3.csv`: total-output versus combustion-output basis.
- `state_summary_central_total_output.csv`: central-scenario state totals.
- `ba_summary_central_total_output.csv`: central-scenario BA totals.
- `supplementary_state_scenario_table_round3.csv`: state totals across scenarios.
- `supplementary_ba_scenario_table_round3.csv`: BA totals across scenarios.
- `dashboard_ba_export_round3_total_output.csv`: BA-level dashboard export.

No facility-level records are included.
